DeepHybrid

22–28% shorter makespans than standard ant colony optimization across six job-shop scheduling benchmarks.

In a job shop, every job has an ordered list of operations, and each machine can handle only one operation at a time. DeepHybrid adapts DeepACO to find schedules that finish all jobs sooner. The time until the final job finishes is the makespan.

With Siripragada Nischala, advised by Dr. Divya Shrivastava.

How the hybrid search works

  1. Model the job shop

    A graph encodes each operation’s duration and machine, the order of operations within each job, and which operations compete for a machine.

  2. Learn a heuristic

    A graph neural network scores scheduling choices using that structure. REINFORCE training rewards schedules with shorter makespans.

  3. Explore feasible schedules

    Ants sample feasible operations using both the learned scores and pheromone trails. Good schedules reinforce their choices while trail evaporation keeps alternatives open.

The learned scores give the search an instance-specific starting point. Pheromone updates then use feedback from the schedules actually sampled, while the custom RL4CO environment enforces job order and machine capacity.
