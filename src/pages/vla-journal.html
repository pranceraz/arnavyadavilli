Research in progress · Robot learning

Can a robot follow a written instruction?

I'm testing how a robot can use camera images and a written instruction to decide what to do next. I'm starting with SmolVLA (a vision-language-action model), LeRobot (the software used to run it), and LIBERO (a set of simulated robot tasks).
